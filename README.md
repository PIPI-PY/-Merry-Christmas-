# Merry Christmas · 粒子圣诞树

夜空里，散着细碎的星光，几片花瓣缓缓飘落

画面最上方，一行手写体的 **Merry Christmas** 由星尘一样的粒子组成，停在夜色里轻轻闪烁

文字之下，三棵圣诞树围成一个三角形立着：冷蓝，冰蓝缀着金，樱粉。正对着的那棵最大、最亮，另外两棵稍稍退后、略小一些。每棵树都是由成千上万颗细小的光点堆出来的圆锥，根部有一圈发光的雪堆，树顶悬着自己的饰物——月亮、星星、爱心

树身上，星星沿着锥面螺旋向上爬升，身后拖着一条由光点组成的星尘尾巴；月亮、金星和爱心也顺着同样的轨迹盘旋上升，最后停在树冠上轻轻浮动

偶尔一颗流星斜斜划过天际，远处绽开几簇烟花，光点散开又慢慢熄灭。
